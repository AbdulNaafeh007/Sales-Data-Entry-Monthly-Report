# Sales Data Entry & Monthly Report Sheet

A beginner-level data entry project built in Microsoft Excel, simulating 
a small business's daily sales tracking and monthly reporting workflow.

## 📋 Project Overview
This project demonstrates structured data entry combined with automated 
reporting — a common task for data entry and admin support roles. Sales 
records are entered into a clean template, and a summary sheet 
automatically generates key business metrics.

## 🔧 What Was Done
- **Manually entered 30 sales transactions** into a structured Excel template 
  (Date, Product, Quantity, Unit Price)
- **Calculated Total per transaction** using formulas (`=Quantity*Unit Price`)
- Built a **Monthly Summary sheet** with:
  - Total Transactions, Total Units Sold, Total Revenue
  - Average Sale Value and Highest Single Sale (using `AVERAGE`, `MAX`)
  - Per-product breakdown using `COUNTIF` and `SUMIF`
- Created a **bar chart** visualizing Revenue by Product

## 📁 File Structure
- `Sales Entries` — raw transaction-level data entry sheet
- `Monthly Summary` — auto-calculated report with formulas and chart

## 🛠️ Tools Used
- Microsoft Excel
- Formulas: `SUM`, `AVERAGE`, `COUNTIF`, `SUMIF`, `MAX`
- Excel Charts

## 🎯 Skills Demonstrated
- Fast and accurate data entry
- Formula-based reporting and summarization
- Data visualization
- Attention to detail in record keeping
